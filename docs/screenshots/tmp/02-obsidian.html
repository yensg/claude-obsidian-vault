tool-calling
Tool calling is how Claude acts on the world — without it, LLMs can only talk; with it, they can run code, read files, and trigger APIs.
1️⃣ What is this really?
Tool calling (also called function calling) is a structured protocol where the LLM outputs a JSON object naming a function and its arguments instead of prose. The host runtime intercepts this, executes the real function, and returns the result to the model. The model then continues generating — incorporating the real result into its response.
2️⃣ Concrete example (from my work)
Building Flight Assistant: when a user asks "is my flight delayed?", Claude calls get_flight_status(flight_id="AA123"). The harness intercepts, hits the airline API, returns live data. Claude then answers with real departure times — not a hallucinated guess.
